Reference

Constants (yellow sheet): c = 2.9979×108 m/s   h = 6.6262×10−34 J·s   hydrogen: En = −2.178×10−18 J ÷ n²

Light: c = λν   E = hν = hc/λ   (nm → m: ×10−9)
Photoelectric: KE = hν − Φ, threshold ν0 = Φ/h
Bohr: ΔE = 2.178×10−18(1/nf² − 1/ni²) J; falling to lower n emits a photon

Quantum numbers: n = 1, 2, 3…; l = 0 to n−1 (s, p, d, f); ml = −l to +l; ms = +½ or −½. A subshell has 2l+1 orbitals; a shell holds 2n² electrons.

Filling order: 1s 2s 2p 3s 3p 4s 3d 4p. Pauli: max 2 e⁻ per orbital. Hund: fill orbitals singly first. Exceptions: Cr = [Ar]4s13d5, Cu = [Ar]4s13d10. Cations lose the highest-n electrons first (4s before 3d).

Trends: across a period radius ↓, IE ↑, EA more negative; down a group radius ↑, IE ↓. Cations are smaller than their atoms; anions are larger.
